
# Research Report

This directory contains the research report for the High-Frequency Bitcoin Volatility Estimation and Forecasting project.

## Report Contents

1. Data loading, cleaning and exploratory analysis
2. Five-minute VWAP and realised variance estimation
3. Volatility forecasting using regression models
4. Trading volume and predictive performance
5. Financial data visualisations
6. Python implementation appendix

## Main Findings

- Analysed over 5 million Bitcoin transactions across four exchanges.
- Constructed 744 hourly realised variance observations.
- Observed peak daily realised volatility of 6.99% on 7 December 2018.
- Found limited out-of-sample predictive performance across forecasting models.
- Identified statistically significant trading volume information, although predictive accuracy remained weak.

The report documents the original academic research and its findings.
